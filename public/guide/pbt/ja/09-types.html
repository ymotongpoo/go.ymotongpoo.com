型から導く生成器

プログラムのすべての構造体に生成器を書くのは手間で、多くの場合、値がどんな姿かは型がすでに語っています。pbtは2つの方法で型から生成器を導きます。実行時にリフレクションで組む Make[T] と、開発時にGoのソースとして書き出す cmd/pbtgen です。

Make

type Order struct {
	ID       int        `pbt:"min=1"`
	Items    []string   `pbt:"min=1,max=5"`
	Note     string     `pbt:"-"` // stays zero
	Placed   time.Time  `pbt:"min=2026-01-01T00:00:00Z,max=2026-12-31T23:59:59Z"`
	Client   netip.Addr // generated with pbt.Addr
	internal int        // unexported fields stay zero
}

var orderGen = pbt.Make[Order](
	pbt.WithField[Order]("Items", pbt.SliceOfN(pbt.StringN(1, 8), 1, 5)),
)

func TestOrders(t *testing.T) {
	pbt.Check(t, func(t *pbt.T) {
		o := orderGen.Draw(t, "order")
		if o.ID < 1 || len(o.Items) == 0 || o.Note != "" || o.Placed.Year() != 2026 || !o.Client.IsValid() {
			t.Fatalf("unexpected order %+v", o)
		}
	})
}

Make[T] は T のフィールドから再帰的に生成器を組みます。pbt 構造体タグでフィールドを調整できます。min と max は数値か、文字列、スライス、マップの長さを制限し、- はフィールドをゼロ値のままにします。生成器を差し替えるオプションが2つあります。WithType(g) はある型のすべての値に効き、WithField[S](name, g) は構造体の1つのフィールドに効きます。上の例では、Items の空でない文字列を WithField で与えています。

Make は、状態が非公開になっている標準ライブラリの型を知っていて、それらには1章の生成器を使います。

型 生成器
time.Time Time。min と max があれば TimeRange
*time.Location FixedZone
netip.Addr、netip.Prefix、netip.AddrPort Addr、Prefix、AddrPort
net.IP Addr のアドレス。4バイトと16バイトの両方の形
net.HardwareAddr HardwareAddr

time.Time のフィールドは、上の Placed のように、min と max をRFC 3339のタイムスタンプで受け取ります。time.Duration は整数型のままで、ほかの int64 と同じように生成されます。

これら以外にも、助けが要る型があります。リフレクションは非公開フィールドに値を設定できないので、非公開フィールドはゼロ値のままです。状態がすべて非公開の型には WithType が要ります。インターフェース、チャネル、関数には導出できる生成器がないので、同じく WithType か WithField が要ります。足りないと Make はフィールド名を示してパニックします。

4章の NoPanic は、検査する関数の引数に Make を使い、同じオプションを受け付けます。

再帰的な型

自分自身を含む型は、何かが再帰を制限しない限り有限の生成器を持ちません。Recursive には葉の生成器と、生成器を1段拡張する関数を渡します。サイズパラメーターが値の段数を制限するので、1つの値のノード数はおおよそサイズになります。

// Expr is a recursive type. Recursive bounds the depth with the size
// parameter, so a value has about size nodes instead of growing without end.
type Expr struct {
	Num  int
	Op   string
	Args []Expr
}

var exprGen = pbt.Recursive(
	pbt.Map(pbt.IntRange(0, 9), func(n int) Expr { return Expr{Num: n} }),
	func(self pbt.Gen[Expr]) pbt.Gen[Expr] {
		return pbt.Custom("op", func(t *pbt.T) Expr {
			return Expr{Op: pbt.SampledFrom([]string{"+", "*"}).Draw(t, ""), Args: pbt.SliceOfN(self, 2, 2).Draw(t, "")}
		})
	},
)

func size(e Expr) int {
	n := 1
	for _, a := range e.Args {
		n += size(a)
	}
	return n
}

func TestExprSize(t *testing.T) {
	pbt.Check(t, func(t *pbt.T) {
		e := exprGen.Draw(t, "expr")
		if size(e) > 4*t.Size()+8 {
			t.Fatalf("%d nodes at size %d", size(e), t.Size())
		}
	})
}

Bounded(leaf, node) は下位の形です。値1つにつき1つの再帰予算を持ち、その値を組み上げる間に取り出すすべての制限付き生成器がその予算を共有します。相互に再帰する2つの型に必要な仕組みです。

Make は、かわりに値全体の大きさを制限します。1つの値には、8*max(size, 1) 単位の成長の割り当てがあります。コレクションの要素、文字列のルーン、Make が試みるマップのエントリ、nilでないポインタは、どれだけ深い位置にあっても1つにつき1単位を消費します。割り当てを使い切ると、コレクションはそれ以上伸びず、再帰的な参照はnilか空のままになります。そのため、1つの値を作る仕事量はサイズに対して線形に増えます。固定のフィールド、配列、タグの最小長は、割り当てを使い切った後も満たします。ただし、最小長を満たそうとすると際限なく再帰する場合は除きます。

// A directory holds files and directories. Make shares one allowance of
// growth across the whole value, so a tree stays proportional to the size
// parameter however the fields nest.
type Dir struct {
	Name  string
	Files []string
	Dirs  []Dir
}

func countNodes(d Dir) int {
	n := 1 + len(d.Files) + len([]rune(d.Name))
	for _, s := range d.Files {
		n += len([]rune(s))
	}
	for _, c := range d.Dirs {
		n += countNodes(c)
	}
	return n
}

func TestDirectoryTrees(t *testing.T) {
	pbt.Check(t, func(t *pbt.T) {
		d := pbt.Make[Dir]().Draw(t, "dir")
		if n := countNodes(d); n > 8*max(t.Size(), 1)+1 {
			t.Fatalf("%d elements at size %d", n, t.Size())
		}
	})
}

BoundedGrowth(g) は、手書きの生成器に同じ割り当てを与えます。g の中で取り出すコレクションとポインタが、その割り当てを共有します。UnboundedGrowth(g) は、一部を外側の割り当てから外します。明示的に差し替えた生成器が、自分の長さの規則を優先させるときに必要な仕組みです。Make は WithType と WithField にこれを使います。

pbtgen

cmd/pbtgen は生成器をソースとして書き出します。コンパイラが検査でき、生成されたファイルはパッケージ自身の中にあるので非公開フィールドにも値を設定できます。

//go:generate go run go.ymotongpoo.com/pbt/cmd/pbtgen -type Order,Customer

go generate は、各型 T について pbt.Gen[T] を返す関数 GenT を pbt_gen.go に書き出します。Make の構造体タグはそのまま効きます。gen=EXPR タグは、フィールドの生成器として使うGoの式を指定します。同じパッケージにある pbt.Gen[string] 型の変数などです。生成されるコードは、標準ライブラリの型に Make と同じ生成器を使い、BoundedGrowth を通して Make と同じ割り当てを使います。そのため、非公開フィールドを持たない型は、相互に再帰する型も含めて、同じシードから Make とpbtgenで同じ値を得ます。非公開フィールドを持つ型では、pbtgenがそのフィールドにも値を設定する分、Make より多くを生成します。

出力を調整するフラグが3つあります。-output はファイル名を指定します。-prefix は関数名の Gen を置き換えます。pbtgenはパッケージがすでに宣言している名前を書き出さないので、手書きの生成器が上書きされることはありません。pbtgenは現在のプラットフォームで go build がコンパイルするファイルを読むので、ビルド制約で除外されたファイルは生成されるコードに影響しません。

型が頻繁に変わるときや、生成器が1つのテストにだけ要るときは Make を選んでください。生成器がパッケージのテスト支援の一部であるとき、非公開フィールドが重要なとき、テスト時のパニックよりコンパイルエラーのほうが望ましいときは、pbtgenを選んでください。
