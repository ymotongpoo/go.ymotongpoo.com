生成器

生成器は pbt.Gen[V] 型の値です。pbtが現在のケースについて記録している選択から V を作る方法を知っていて、その記録が縮小と再現を支えています。記録を自分で組むことはありません。生成器を組み合わせて、そこから値を取り出すだけです。

組み込みの生成器

値 生成器
整数 Int、IntRange、IntMin、IntMax、IntRangeToward。Int32、Int64、Uint、Uint32、Uint64、Byte とそれぞれの Range 版。任意の整数型には Integer[I] と IntegerRange[I]
浮動小数点数 有限の値には Float64、Float64Range、Float32、Float32Range。AnyFloat64 はNaNと無限大を加える
文字と文字列 Bool、Rune、String、StringN、StringOf、StringOfN、Bytes、BytesN
コレクション SliceOf、SliceOfN、SliceOfDistinct、SliceOfNDistinct、MapOf、MapOfN、Permutation
選択 Just、SampledFrom、OneOf、Frequency、Ptr
関数 Func、Func2。コールバックを受け取るコードのプロパティ向けに、純粋な関数を生成する
任意の値 一般的な型を限られた範囲で混ぜる Any と、型から生成器を導く Make[T]（9章）

整数は、バグが潜みやすい範囲の境界と小さな値に寄ります。文字列とコレクションの長さは、ケースのサイズパラメーターに従います。最大長の -1 は上限なしを意味します。

自分の生成器を作る

pbt.Custom は *pbt.T を受け取る関数を生成器にします。その中では、他の生成器から任意の順序と制御構造で値を取り出せます。

type User struct {
	Name  string
	Age   int
	Email string
}

// userGen builds a User from smaller generators. Labeled draws inside a
// generator appear in the report, indented under the value they build.
var userGen = pbt.Custom("user", func(t *pbt.T) User {
	name := pbt.StringOfN(pbt.SampledFrom([]rune("abcdefghijklmnopqrstuvwxyz")), 1, 12).Draw(t, "name")
	return User{
		Name:  name,
		Age:   pbt.IntRange(0, 120).Draw(t, "age"),
		Email: name + "@example.com",
	}
})

Custom に渡した名前が、報告でのこの生成器の表記になります。中で行う取り出しのラベルにも役割があります。生成器の中でラベルを付けて取り出した値は、組み上げた値の下に字下げして報告に並びます。"" でラベルを付けなかった値は報告に出ません。それ自体には関心のない値には、この扱いが向いています。

生成器を組み合わせる

組み合わせの大半は3つの関数で書けます。

// Map transforms a value, Filter keeps the values that satisfy a predicate,
// and Bind picks the next generator from a value.
var (
	even    = pbt.Map(pbt.IntRange(0, 500), func(n int) int { return 2 * n })
	nonZero = pbt.Filter(pbt.Int(), func(n int) bool { return n != 0 })
	matrix  = pbt.Bind(pbt.IntRange(1, 4), func(n int) pbt.Gen[[][]int] {
		row := pbt.SliceOfN(pbt.Int(), n, n) // every row has the same length
		return pbt.SliceOfN(row, 1, 4)
	})
)
  • Map は各値に関数を適用します。結果は入力と同じように縮小します。
  • Filter は述語を満たさない値を捨てて引き直します。大半の値を捨てる述語は実行を遅くし、pbtは何度も捨てたケースを諦めます。Filter(Int(), positive) より IntRange(1, 100) のように、欲しい値を直接作るほうを選んでください。
  • Bind は値から次の生成器を選びます。値の一部を別の部分に依存させる手段で、PropErでは ?LET と呼びます。

OneOf は複数の生成器から等確率で1つを選び、Frequency は重みで選びます。どちらも2章で扱います。Ptr は値をポインタで包み、nil を含めるかどうかを選べます。Lazy は生成器の構築を最初に値を取り出すときまで遅らせます。再帰的な生成器が自分自身を参照するために必要で、上限を付けた形は9章で示します。

報告は値の組み上がり方を示す

User で失敗するプロパティの報告には、そのユーザーと、その下にラベル付きの部品が並びます。

var displayNameProperty = func(t *pbt.T) {
	u := userGen.Draw(t, "user")
	display := strings.ToUpper(u.Name[:1]) + u.Name[1:]
	if unicode.IsLower(rune(display[0])) {
		t.Fatalf("display name %q is not capitalized", display)
	}
	if len(display) > 8 {
		t.Fatalf("display name %q is too long for the badge", display)
	}
}

[pbt] property failed after 3 passed checks and 145 shrink steps (size 4)
[pbt] user (user) = snippets.User{Name:"aaaaaaaaa", Age:0, Email:"aaaaaaaaa@example.com"}
[pbt]   name (StringOfN(SampledFrom(26 values), 1, 12)) = "aaaaaaaaa"
[pbt]   age (IntRange(0, 120)) = 0
[pbt] error: display name "Aaaaaaaaa" is too long for the badge
[pbt] reproduce: go test -run 'TestDisplayName' -pbt.seed=0x1

名前は、長さの検査にまだ引っかかる最短の文字列である a 9文字まで縮みました。年齢は失敗に関係しないので0まで縮んでいます。報告はラベル付きの値を3段の深さまで載せ、1つの値を2000文字で切ります。ReportDepth と ReportLimit のオプションで両方を変えられます。

プロパティの外で値を見る

Example は生成器の値を1つ返します。生成器の出力を手早く確かめるときや、従来のテストでそれらしい入力が必要なときに使います。シードを渡すと値が固定されます。

func TestExample(t *testing.T) {
	u := userGen.Example(42) // a sample outside any property; the seed fixes it
	if u.Age < 0 || !strings.HasSuffix(u.Email, "@example.com") {
		t.Fatalf("unexpected user %+v", u)
	}
}

生成器が共有する値

Just(v) はすべてのケースに同じ v を返します。v がスライス、マップ、ポインタなら、すべてのケースが同じオブジェクトを見ます。プロパティがそれを変更すると、後のケースと報告が見るものも変わってしまいます。SampledFrom(values) はスライスをコピーしますが、要素はそのまま渡します。プロパティが値を変更する必要があるなら、Custom で毎回新しい値を作ってください。
